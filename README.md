## ⚡ Core Interactive Features

### 1. 🤖 AI Recruiter Match & Pitch Simulator (`#matcher`)
- **3-Column Selection Engine**: Recruiters select their open Target Role (*Frontend / React Engineer*, *Full-Stack MERN Developer*, *AI / RAG Engineer*, or *Software Development Engineer*), desired Tech Vibe, and Team Culture Perk.
- **Real-Time Compatibility Scan**: Simulates an automated multi-step radar evaluation with custom progress tracking and celebratory confetti.
- **Tailored Alignment Pitch**: Dynamically generates both a **Technical Proof Point** (grounded in Ajay's actual production code) and a witty **Honest Dev Verdict**.
- **1-Click Dispatch**: Seamlessly transfers match specifications directly into the Fast-Track Contact Form.

### 2. 📬 Interviewer Fast-Track Email Send Box (`#contact`)
- **1-Click Interview Templates**: Instantly auto-fills invitations for *Full-Stack Interviews*, *AI / Data Science Inquiries*, or *Informal Coding Coffee Chats*.
- **Direct Dispatch & Client Mailto**: Supports simulated direct dispatch with celebration triggers or launches the native email client (`mailto:`) with all role specs and interview slots pre-populated.
- **Instant Clipboard Pills**: 1-click clipboard copy with real-time feedback for both email and phone.

### 3. 🎭 Dual Perspective: Recruiter Mode vs. Honest Dev Mode
- A global toggle in the navigation bar dynamically swaps content across the entire application:
  - **Recruiter Mode**: Metric-driven, formal corporate summaries designed for hiring managers.
  - **Honest Dev Mode**: Candid, witty behind-the-scenes engineering realities, debugging war stories, and caffeine-fueled epiphanies.

### 4. 💻 Interactive Developer Shell (`DevTerminal`)
- An interactive retro-modern terminal drawer accessible from the hero section or a persistent floating shell launcher button.
- Built-in command interpreter supporting:
  - `help` — Lists available terminal commands.
  - `skills` — Prints verified competencies and percentages.
  - `projects` — Summarizes featured software systems.
  - `contact` — Outputs personal communication channels.
  - `chai` — Brews a virtual cup of tea and overclocks developer velocity.
  - `hire-ajay` — Triggers celebratory confetti bursts and VIP interview credentials.
  - `clear` / `exit` — Manages console history and drawer state.

### 5. ☕ Virtual Kadak Chai Fuel Telemetry
- Interactive tea brew counter integrated into the navigation bar that powers a live **Chai Fuel Telemetry Gauge** in the hero section and displays witty developer velocity toasts.

### 6. 🐛 Roaming Bug Squasher Mini-Game
- An animated bug jumps randomly across screen coordinates. Clicking it spawns floating `+1 Bug Squashed! 🐛` popups, increments the navbar telemetry, and rewards the player with celebratory confetti every 5 squashed bugs.

### 7. 🎨 Visual Polish & Micro-Animations
- **Interactive Cursor Spotlight**: Smooth radial indigo gradient tracking cursor coordinates across the dark slate canvas.
- **Top Scroll Progress Indicator**: Real-time gradient progress bar indicating page depth.
- **Infinite Marquee Ticker**: Smooth horizontal CSS ticker highlighting academic honors and technical milestones (pauses on hover).
- **3D Perspective Tilt Cards**: 3D hover transforms (`rotateX`, `rotateY`, `scale`, and glowing box shadows) across all cards.
- **Hero Typewriter Effect**: Smoothly cycles through candidate titles with blinking terminal cursor.

## 💻 Local Development Setup

To run this portfolio locally on your machine:

```bash
# 1. Clone the repository
git clone https://github.com/Ajayteli5252/Porfolio-website.git

# 2. Navigate to the project directory
cd Porfolio-website

# 3. Install dependencies
npm install

# 4. Start the Vite development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) (or the port indicated in terminal) in your browser.

To create a production build:

```bash
npm run build
```
